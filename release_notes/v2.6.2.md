## 🐛 Bug Fixes

### Thumbnails now persist between app sessions
Previously, when the app was left unused for a day or two, all photo
thumbnails would go blank on re-open and require a network reload.
This was caused by Android's OS silently clearing the app's temporary
cache directory (`cacheDir`) during inactivity.

**Fixed:** Photo thumbnails are now stored in persistent app storage
(`filesDir`) which Android never clears automatically. Thumbnails appear
instantly even after weeks of not opening the app — no internet required
for photos you've already viewed.

## ⚡ Performance Improvements

- **Proactive thumbnail pre-caching** — images are now automatically downloaded in the background as soon as their CDN URLs are resolved. You no longer need to scroll slowly through an album for the first time to cache them.
- **Faster album loading on re-open** — URL resolution now runs in the
  background while thumbnails load from disk simultaneously, instead of
  blocking the UI while waiting for network
- **Reduced Telegram API calls** — CDN URL refresh interval extended from
  23 hours to 6 days; most app opens now require zero API calls for
  photos already in cache

## 🔧 Under the Hood

- Automated CI/CD pipeline: every push to `main` now automatically
  builds and publishes a signed release APK to GitHub Releases
