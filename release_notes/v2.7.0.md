### RoutePix v2.7.0 Release Notes

**🚀 New Features & Enhancements**
* **Native Telegram Integration**: Replaced the old manual configuration flow with a robust, native TDLib client implementation built directly into the app.
* **One-Tap Bot Setup**: You can now securely link your personal Telegram account in-app. RoutePix will automatically talk to `@BotFather` in the background to instantly generate your Bot Token and fetch your Chat ID. No more juggling between apps!
* **Revamped Settings UI**: Cleaned up the Telegram Configuration block. It now intelligently tracks your live connection status and dynamically adapts its options (e.g., swapping to "Change Linked Telegram Account").
* **Manual Fallback Link**: Added a sleek, properly styled button for users who still prefer the step-by-step manual setup.

**🐛 Bug Fixes & Reliability**
* **Infinite Spinner Resolved**: Fixed a critical state-management bug where logging out of the linked Telegram account, or dismissing the configuration sheet, would result in an infinite loading spinner.
* **Smart Error Handling**: If automated bot creation fails (e.g., hitting Telegram's 24-hour rate limit on new bots), the app now captures and displays BotFather's exact response so you aren't left guessing.
* **BotFather Timing Fixes**: Resolved race-conditions where the automated `/newbot` commands were misfiring because they were capturing BotFather's stale welcome messages.

**🛠️ Under the Hood**
* Integrated the official `org.drinkless.tdlib` binaries via Maven Central.
* Added native `libtdjni.so` extraction support across all major architectures (arm64-v8a, armeabi-v7a, x86, x86_64).
* Created a scalable, state-flow driven architecture via `TelegramClientManager` for real-time Telegram event tracking.
